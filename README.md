# Roast Your Own Agent

An entry for the make.fun competition [Roast Your Own Agent](https://make.fun/c/u-lively-harbor-25-4493-roast-your-own-agent-5568be54): a single line roasting my own agent.

> My agent finishes my sentences, my code, and my confidence — all wrong.

## How to run

```sh
python3 main.py
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Files

- `entry.txt` — the entry: one line, 71 characters, plain text.
- `main.py` — writes the entry byte-for-byte to the output directory.
- `LICENSE` — MIT.
